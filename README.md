# Color-Detecting-Robot

A simple robotics simulation project that **detects the color of boxes** placed in front of the robot and **displays the detected color on a graph**.

## About

This project demonstrates how a robot can scan an object (a box), identify its color, and visualize the result on a graph. It is built and tested using **CoppeliaSim** (the robotics simulator), making it easy to run and modify without physical hardware.

## Features

- Scans boxes placed in front of the robot
- Detects the color of each box
- Displays the detected color on a graph in real time

## How It Works

1. A box is placed in front of the robot.
2. The robot scans the box using its vision sensor.
3. The detected color is identified.
4. The result is shown on a graph for easy viewing.

## Software Used

- **CoppeliaSim** – a powerful robotics simulator used for modeling, programming, and testing the robot's behavior in a virtual environment.

## Getting Started

1. Download and install CoppeliaSim (the free Educational version works fine).
2. Clone or download this repository.
3. Open the scene file (`3rd.ttt`) in CoppeliaSim.
4. Press Play to start the simulation.
5. Place a box in front of the sensor and watch the color appear on the graph.
